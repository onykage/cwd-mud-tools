# WinTin 1.73

WinTin is William Lees' Windows port of TinTin++ 1.64 (wintin.org, 2000), the client many
Legends of Fate players used. Kept here as it was released; see `README.TXT` for the author's own
notes and `winhlp.htm` and `tintin15.txt` for the manual. Windows only (it runs under Wine
elsewhere). For a maintained TinTin++, see [tintin.mudhalla.net](https://tintin.mudhalla.net).

## Using it with Chat with Dragons

Run `wintin95.exe`, then type:

```
#session cwd dragonchat.app 4000
```

## Files

- `wintin95.exe`, `README.TXT`, `winhlp.htm`, `tintin15.txt`, `SAMPLE.CMD`: WinTin 1.73 as
  released.
- `cleric.txt`, `druid.txt`, `prac.txt`, `scanner.txt`, `ewar.txt`, `ding.wav`: a player's own
  trigger and alias files from 2010-2011, kept as period examples. `ewar.txt` was written for
  EverWar; its login lines are blanked (put your own name and password in your copy only).
