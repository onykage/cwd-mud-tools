Release Notes for Wintin version 1.73
-------------------------------------


What is Wintin?
---------------

Wintin is a Windows port of Tintin++, the (T)he K(I)cki(N) (T)ickin D(I)kumud Clie(N)t. Many thanks to Peter Unold, who wrote the original Tintin, Bill Reiss, David Wagner, Joann Ellsworth, Jeremy Jack, who wrote tintin++, and L Kahn, who turned it into a Windows NT Console Application. Wintin is based on their work.

For those who know tintin++, WinTin is based on tintin++ version 1.64 patch level 4, the very last version of tintin++ to be released. All commands are supported apart from suspend and system.

Setup Instructions
------------------

Just copy the files to a directory on your hard drive and create an icon for Wintin95.exe. Help is accessible from within Wintin, and contains full(ish) instructions on use. If you are new to tintin or wintin I strongly reccommend that you read the tintin manual: it is called tintin15.txt and is included in this archive, with thanks to David Wagner for allowing me to include it. 

Contacting the Author
---------------------

Wintin now has its own domain, wintin.org. New versions of Wintin will be released
on the web site http://www.wintin.org, and you can reach the author, William Lees,
at the mail address william@wintin.org. If you're having problems with wintin, please
check the help file and the web site before mailing, as it's quite likely that you 
will find the problem answered there.
